# Multi-language Infrastructure Plan

## Goal
Define and maintain i18n strategy for mobile UI and validation messages.

## Decisions to track
- Localization library and message loading strategy
- Translation key naming conventions
- Fallback language behavior
- Pluralization and interpolation rules

## Rollout checklist
- Extract hardcoded strings from screens/components
- Add key coverage tests for critical flows
- Validate locale switching in major journeys
